What every commercial license includes:

- one closed-source Product, on any number of platforms and domains under the same name
- unlimited end users and devices, including app stores
- running the Product yourself, in the browser or as a hosted application, for your Product's own features
- private changes to Hyper for use in the Product
- every release published while the license is paid
- contractors working on the Product for you

No license key is needed. Licenses renew each year unless cancelled; if one ends, end users keep the copies they already installed.

What needs OEM terms: putting Hyper inside another company's product, selling it as an SDK, library or command line tool, or offering it as a hosted service or API that other developers or software use. For OEM terms, contact us at [contact@bentopdf.com](mailto:contact@bentopdf.com).

BentoPDF's commercial license already includes Hyper as a bundled component for eligible products: companies under US$1 million in revenue and funding, using it through BentoPDF's own tools on the end user's device.
